# music/

Optional: Leg hier deine Audiodateien ab, wenn du die App **lokal** startest
(z. B. `python3 -m http.server 8000`). Die Dateinamen müssen exakt dem Feld `file`
in `data/songs.js` entsprechen.

Dieser Ordner ist in `.gitignore` eingetragen. Deine Musik wird nie zu GitHub hochgeladen.

Einfacher geht es meist über **Musik → Ordner verbinden** direkt in der App.
